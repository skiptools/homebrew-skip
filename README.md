# homebrew-skip
Homebrew repository for Skip

Skip is distributed as an official Homebrew Formula at
https://formulae.brew.sh/formula/skip
and can be installed with:

```shell
brew install skip
```

You can also install it from a custom Cask build
hosted through this homebrew-skip repository
(which is necessary for installing on intel macOS hosts)
with the command:

```shell
brew tap skipstone/skip
brew install skipstone/skip/skip
```

For more information on getting started with Skip, see
https://skip.dev/docs/gettingstarted/
